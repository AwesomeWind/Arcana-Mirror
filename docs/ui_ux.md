# Tarot AI - UI / UX Design v0.1

## 1. 设计目标

本产品 UI 的核心不是“功能页面”。

而是营造一种：

**安静、神秘、沉浸、有仪式感的塔罗牌占卜体验。**

用户进入后应该感觉：

- 与外界隔离
- 正在进行私人占卜
- 面前有真实的占卜桌
- AI 占卜师正在观察自己
- 每一步都具有意义

视觉体验优先级：

```
沉浸感 > 仪式感 > 易用性 > 信息密度
```

页面整体尽量克制。

避免：

- 太多按钮
- 太亮
- 太拥挤
- 太像普通 Web App

------

# 2. 全局视觉风格

## 背景

深色幻想风格。

建议颜色：

```
Background:
#09070d

Secondary:
#15101f

Accent Purple:
#6f4cff

Gold:
#d8b36a

Soft Glow:
rgba(111,76,255,0.2)
```

背景层次：

- 深色渐变
- 微弱星点
- 轻微漂浮粒子

------

## 主舞台

占卜桌为页面中心。

比例：

```
宽：70~80%

高度：桌面占中间区域
```

视觉：

- 木纹 / 暗金纹理
- 圆形魔法阵
- 金色符号
- 紫色辉光

------

## 字体

标题：

优雅 serif

正文：

现代 sans-serif

建议：

```
Title:
Cormorant Garamond

Body:
Inter
```

------

## 光影

页面需要：

- 柔和发光
- 微阴影
- 蜡烛动态火光

避免硬阴影。

------

# 3. 页面结构

整个产品使用：

**单页面状态切换**

不跳转。

通过动画切换阶段。

状态：

```
arrival
shuffle
spread
draw
reveal
reading
```

位置：

桌子对面中央。

- 看不清五官

位置：

- 圆角

## 气泡

- 微发光

淡入 + 上浮

# 10. 动画原则

节奏：

慢。

建议：

```
0.4s 轻微响应
1s~2s 仪式动画
```

------

## 常用动效

使用：

- fade in
- glow pulse
- scale
- rotate
- floating
- particle drift

避免：

- 快速跳动
- 高频闪烁
